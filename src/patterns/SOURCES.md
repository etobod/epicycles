# Sources of the sample patterns

Two SVG drawings to open with "Load SVG". Both are public domain /
CC0. Each row: file, title, source (detail page URL), author, licence. The files are
reduced to `path` / `polyline` only, with every `transform` applied to the coordinates
and all styles, metadata, `defs` and comments removed; the source URL points at the
original drawing.
