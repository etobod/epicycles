# Sources of the preset patterns

Ten SVG drawings to open with "Load SVG". All of them are public
domain / CC0. Each row: file, title, source page (states the title, author and licence),
raw file actually downloaded, author, licence. The files are reduced to `path` only, with
every `transform` applied to the coordinates and all styles, metadata, `defs` and comments
removed; the source page points at the original drawing.
